## BOGYO v0.1.0 — first public release

**Find and fix your own servers' vulnerabilities before attackers do.**
BOGYO is a consent-gated, fail-closed defensive security toolkit for Linux
servers **you own or are explicitly authorized to test**.

### Highlights
- 🛡️ **One gate, fail-closed** — every active action goes through `ScopeGuard`:
  signed ownership scope + consent, kill-switch, default-deny toggles, dry-run by default.
- 🚫 **Auto-block attackers** — detect brute force in auth logs and drop the source IPs
  with nftables. Inbound only; no hack-back, ever.
- 🧪 **Sandbox-only attack validation** — replay findings in an isolated Docker replica;
  refused on production; isolation enforced by structural compose analysis.
- 🔧 **Patch loop** — propose hardening (rules / local AI / Claude), check it for
  conflicts in the sandbox, apply only with explicit human approval.
- 🕸️ **Own-server patch mesh** — your servers share patches over a rolling-key channel
  and a signed patch chain; each applies a peer's patch only after its own sandbox check passes.
- 📊 **Dashboard & control API** — live TUI, JSON state, usage governor for Claude tokens.
- 📜 **Tamper-evident audit log** for every allow/deny and action.

### Get started
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
sentinel init && sentinel keygen && sentinel sign-scope && sentinel consent
sentinel status
```
